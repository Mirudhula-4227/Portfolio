# Under Open Skies — Portfolio

A responsive React + TypeScript portfolio for Mirudhula, with a dark aurora-inspired visual theme. Project technology labels still need to be replaced with the actual tools used, and the bio/skills can be further personalized.

## Live website

GitHub Pages deploys the site automatically when changes are pushed to `main`: https://mirudhula-4227.github.io/Portfolio/

## Run locally

Install dependencies with `npm install`, then start the dev server with `npm run dev`. Vite prints a local URL in the terminal.

## Build

Run `npm run build` to type-check and create the production build in `dist/`. Run `npm run preview` to preview that build locally.

## Customize

- Update the personal copy in `src/App.tsx`.
- Update project descriptions and technology labels in the `projects` array to match the final work.
- Update the `skills` array and personal copy with your own experience.
- Adjust colors, layout, and animations in `src/styles.css`.
- See [CASE_STUDY.md](CASE_STUDY.md) for the project concept, sections, references, tech stack, and learning outcomes.
