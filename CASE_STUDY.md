# Case Study — Under Open Skies

## 1. Portfolio name and concept

**Under Open Skies** is a personal portfolio concept inspired by the aurora borealis. A near-black night palette, soft green-blue light, small stars, and mountain silhouettes create a calm setting for presenting creative work. The visual direction is intended to feel curious, thoughtful, and quietly expressive.

## 2. Pages and sections

The site is a responsive single-page portfolio with anchor navigation:

- **Home / Hero** — A concise introduction, availability label, and links to the work and about sections. It gives visitors an immediate sense of the portfolio’s personality.
- **About** — A short personal introduction and interests, adding context beyond a list of skills.
- **Skills** — Design, development, and toolkit groupings make capabilities easy to scan.
- **Projects** — Three project cards present SOS Disaster Management App, Spec to RTL Conversion Application, and VeriMed Application with short descriptions. The technology labels are intentionally left for the author to complete with the tools actually used.
- **Contact** — A clear email call-to-action links directly to Mirudhula at mirudhulabm@gmail.com.
- **Footer** — Returns visitors to the top and closes with a small visual sign-off.

## 4. Tech stack

- **React** — reusable interface and responsive navigation state.
- **TypeScript** — typed component code.
- **Vite** — development server and production bundling.
- **HTML and CSS** — semantic structure, responsive layout, project artwork, and animations.
- **Google Fonts** — typography pairing: Manrope for display headings, DM Sans for body text, and DM Mono for labels.

## 5. Animations and interactions

- Two blurred aurora ribbons drift slowly above the hero using CSS keyframes.
- Small star details and the logo sparkle add atmosphere; the sparkle rotates slowly.
- Project artwork symbols and arrows respond to hover.
- Buttons lift slightly on hover, and navigation links change color.
- The mobile menu opens and closes with a button that exposes its expanded state to assistive technology.
- Smooth anchor scrolling connects the page sections.
- `prefers-reduced-motion` disables or minimizes animation and transitions for visitors who request reduced motion.

## 6. Learning outcomes

This project demonstrates how to plan a visual theme and carry it consistently through typography, color, layout, and decorative artwork. It also provides practice with responsive CSS, React component rendering, TypeScript, semantic HTML, keyboard focus states, mobile navigation, and reduced-motion accessibility. A useful next step is replacing the sample content with real work and testing the finished portfolio on multiple devices.
